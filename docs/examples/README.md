# Sample Charts

These SVG charts are generated by GitHub Star Tracker. By default they adapt to dark and light mode via `@media (prefers-color-scheme: dark)`; you can force a palette with `chart-theme: light|dark`. Toggle your system or browser theme to see the effect.

This page is the visual reference for the chart options, with three exceptions: `chart-trend-line`, `chart-animation` and `email-theme` have no sample render here. The first two cannot be shown as a static before/after pair, and the third only affects the email path. Each comparison below uses the same data so only the option being demonstrated changes. See **[Star Trend Charts](https://github.com/fbuireu/github-star-tracker/wiki/Star-Trend-Charts)** for the prose docs.

## Curve Styles (`chart-curve`)

The curve used to connect points when `chart-smoothing` is on. All four use the same stepped data so the differences are clear: `monotone` (default), `cubic-bezier` and `rounded-step` keep the plateaus flat; only `catmull-rom` overshoots at the foot of a step, dipping below the previous value.

| `monotone` (default) | `catmull-rom` |
|---|---|
| ![monotone](curve-monotone.svg) | ![catmull-rom](curve-catmull-rom.svg) |

| `cubic-bezier` | `rounded-step` |
|---|---|
| ![cubic-bezier](curve-cubic-bezier.svg) | ![rounded-step](curve-rounded-step.svg) |

> Email charts (QuickChart) approximate these: `monotone` is exact, `rounded-step` falls back to `monotone`, and `catmull-rom` and `cubic-bezier` both render as a tensioned spline.

> Those two values share a cell only for a reader in light mode. The left render is the default `auto`,

### `chart-range`

Narrows the time window, measured back from the latest point.

| `all` (default) | `1y` | `90d` | `30d` |
|---|---|---|---|
| ![all time](option-range-all.svg) | ![last year](option-range-1y.svg) | ![last 90 days](option-range-90d.svg) | ![last 30 days](option-range-30d.svg) |

All four are rendered from the same weekly history. `chart-max-points` (default 30) controls resolution,
not the span: each chart spreads its 30 points evenly across the window `chart-range` selected, so the
narrower the range the denser the real detail.

### `chart-max-points`

Curve resolution across the span. `0` reconstructs at weekly cadence (point count scales with the repo's age).

| `30` (default) | `0` (weekly) | `10` (coarse) |
|---|---|---|
| ![30 points](option-maxpoints-default.svg) | ![weekly](option-maxpoints-weekly.svg) | ![coarse](option-maxpoints-coarse.svg) |
